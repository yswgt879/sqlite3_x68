# SQLite3 for X68000

## はじめに

SQLite3 を軽量化し、X68000向けに移植しました。

ローカルドライブ（FD・HD）の他、エミュレータのホスト共有やネットワークドライブ上でも動作します。

## 動作環境

* X68000実機（X68000/X68030）・X68000 Z・各種X68000エミュレータ
* Human68k 全バージョン
* メモリ2MB以上

## バージョン情報

* SQLite3 Version : 3.53.3
* X68000 Version  : 0.26.7.2.01

## コンパイル方法 (Mac クロス環境のみ)

ターミナルで以下のコマンドを実行します。

```bash
make
```

[クロス開発環境 elf2x68k](https://github.com/yunkya2/elf2x68k)用に作成されております。

環境に合わせて `Makefile` 内のコンパイラパスを変更してください。

## X68000での使い方

### 起動方法
引数に、 **保存したいデータベースのファイル名** （`拡張子は.db`）を指定して起動してください。

（ファイルが存在しない場合、自動でメモリに作成されますが、ファイルに保存されません）

```Human68k
sqlite3.x test.db
```

### SQL操作の例
起動すると `sqlite>` プロンプトが立ち上がります。

```sql
sqlite> CREATE TABLE x68k(id INT, model TEXT);
sqlite> INSERT INTO x68k VALUES(0, 'X68000');
sqlite> INSERT INTO x68k VALUES(1, 'X68000 XVI');
sqlite> SELECT * FROM x68k;
id|model
--+----------
 0|X68000
 1|X68000 XVI

sqlite> .quit
```
`.help`で、コマンドのヘルプ（一覧）が表示されます。

`.quit` で終了後、X68000を再起動してから再度 `sqlite3.x test.db` を実行しても、データは消えずにディスクからロードされます。

その他、コマンドの詳細については、SQLite3のドキュメントをご覧ください。

## 他のOS（Windows / Mac / Linux）とのファイル互換性について

本プログラムが生成する `.db` ファイルは、 **現代のPC環境と100%の相互互換性** があります。

X68000で作成したファイルを他のOSに持って行って各種GUIツール等で開くことも、その逆も可能です。

### 【重要】他のOSからファイルをX68000に持ち込む際の注意点

本バイナリはX68000の省メモリ（2MB等）運用のために、ディスクの管理ページサイズを最小の **512バイト** に設定しています。

（`-DSQLITE_DEFAULT_PAGE_SIZE=512`）<br>

他のOS側でデータベースファイルを新規作成すると、デフォルトの **4096バイト（4KB）** ページで作成されてしまい、X68000でのメモリ圧迫や予期せぬ挙動の原因となります。

他のOS側でX68000向けのデータベースファイルを先行作成（事前データ入力など）する場合は、 **空のファイルを開いた直後（テーブルを作成する前）** に、必ず以下のSQLを実行してファイル構造を512バイトに指定してください。

```sql
-- 他のOS側のSQLiteツール等で実行
PRAGMA page_size = 512;
VACUUM;
```

この処理を行った `.db` ファイルであれば、X68000でも読み書きが可能です。

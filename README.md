# SQLite3 for X68000

## はじめに
[SQLite3](https://sqlite.org) を軽量化し、X68000向けに移植しました。

ローカルドライブ（FD・HD）の他、エミュレータのホスト共有やネットワークドライブ上でも動作します。

## 動作環境

* X68000実機（X68000/X68030）・X68000 Z・各種X68000エミュレータ
* Human68k 全バージョン
* メモリ2MB以上

## バージョン情報

* SQLite3 Version : 3.53.3
* X68000 Version  : 0.26.7.2.02

## コンパイル方法 (Mac クロス環境のみ)

ターミナルで以下のコマンドを実行します。

```bash
make
```

[クロス開発環境 elf2x68k](https://github.com/yunkya2/elf2x68k)用に作成されております。

環境に合わせて `Makefile` 内のコンパイラパスを変更してください。

## X68000での使い方

### 起動方法
引数に、 **保存したいデータベースのファイル名** （`拡張子は.db`）を指定して起動してください。

（ファイルが存在しない場合、自動でメモリに作成されますが、ファイルに保存されません）

```Human68k
sqlite3.x test.db
```

### SQL操作の例
起動すると `sqlite>` プロンプトが立ち上がります。

```sql
sqlite> CREATE TABLE x68k(id INT, model TEXT);
sqlite> INSERT INTO x68k VALUES(0, 'X68000');
sqlite> INSERT INTO x68k VALUES(1, 'X68000 XVI');
sqlite> SELECT * FROM x68k;
id|model
--+----------
 0|X68000
 1|X68000 XVI

sqlite> .quit
```
`.help`で、コマンドのヘルプ（一覧）が表示されます。

`.quit` で終了後、X68000を再起動してから再度 `sqlite3.x test.db` を実行しても、データは消えずにディスクからロードされます。

その他、コマンドの詳細については、SQLite3のドキュメントをご覧ください。

## 他のOS（Windows / Mac / Linux）とのファイル互換性と注意点

本プログラムが生成する `.db` ファイルは、現代のPC環境と100%の相互互換性があります。

X68000で作成したファイルを他のOSに持って行って各種GUIツール等で開くことも、その逆も可能です。

Windows や Mac などの現代のPC環境で作成されたデータベースファイル（`.db` / `.sqlite3`）は、管理単位であるページサイズがデフォルトで 4096バイト（4KB）に設定されています。

本バイナリは、PC側で作成された 4096バイトのデータベースファイルをそのまま X68000 に持ち込んで読み書き（SELECT / INSERT 等）を行うことが可能です。

### メモリ（2MB環境）での運用の注意点
小規模なデータであればデフォルトの4096バイトのままでも問題なく動作しますが、データ件数が数百〜数千件に増えた場合や、複雑な並び替え（`ORDER BY` 等）を行った際に、メモリ不足エラーが発生する原因となる場合があります。

実機最小限の2MBという限られたメモリ環境で巨大なデータをより安全に運用するためには、あらかじめPC側で以下のコマンドを実行し、ファイルを 512バイト に変換してから実機へ持ち込むことを推奨します。

```sql
-- PC側のSQLiteツール等で実行してファイル構造を変換するコマンド
PRAGMA page_size = 512;
VACUUM;
```
